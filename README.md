# ROBOT LINE FOLLOWER KRI GANAS - STM32H743
### Kontes Robot Indonesia 2026 | PaYancee Robotik - Bandung

Robot line follower high-speed 480MHz untuk track KRI.
- Mikrokontroler: STM32H743VIT6 480MHz
- Sensor: 16x QTR-8RC
- Driver: TB6612FNG
- Algoritma: PID + Feedforward Speed Profiling

## Fitur Ganas
- PID Loop 1kHz
- Auto Speed Down di tikungan 90°
- Kalibrasi sensor otomatis

## Wiring
STM32H743 -> TB6612 -> Motor N20
